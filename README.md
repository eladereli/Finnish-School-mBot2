
# Introduction to mBot2

## What is mBot2?
mBot2 is an educational robot made by Makeblock. It helps students learn coding and robotics.

## What can mBot2 do?
mBot2 can perform different tasks using its sensors, motors, and lights.

Some of its features are:
- Moving forward and backward.
- Following lines.
- Detecting obstacles.
- Displaying information.
- Playing sounds.

## What is CyberPi?
**CyberPi** is the main controller of mBot2. It controls the robot and its different functions.

## Three important features of mBot2
1. Sensors that collect information.
2. Motors that help the robot move.
3. RGB LEDs that display different colours.

## Why do we use mBot2 in ICT lessons?
We use mBot2 to learn programming in a practical way. It helps us understand how **coding and robotics** work together.

*Learning with robots makes ICT lessons more interesting.*
