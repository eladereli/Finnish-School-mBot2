# Finnish-School-mBot2
What is mBot2?
mBot2 is an educational robot used to learn programming and robotics.

What can mBot2 do?
mBot2 can move, follow lines, play sounds, and display information.

What is CyberPi?
CyberPi is the main controller of mBot2. It helps control the robot and its different functions.

Three important features of mBot2
1. Sensors
2. Motors
3. LED lights

Why do we use mBot2 in ICT lessons?
We use mBot2 to learn coding, problem-solving, and robotics in a practical way.
